How day sheets work
Queues are automatic — each station shows the jobs whose work is due that day, derived from the Scheduler's spray/assembly dates (cut & framing = spray − 2 working days; lid = day before assembly). Red rows are overdue carry-overs. Est hrs = the job's build time × that station's share (draft weights).
Non-sold tasks (deliveries, maintenance…) can be added to any station for the day — placeholder names until Dan's list lands.
🖨 Print gives one A4 page per station with pen columns (actual hrs / who / ✓ / notes).
Day-close: at the end of the day, type the paper numbers into the same grid and hit Save — that's the data that refines build times, the bespoke calculator and the per-person reports.
